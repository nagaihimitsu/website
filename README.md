# Personal Atlas

日光の入る3Dの部屋と一体になったコレクションモードで、訪れた国と都道府県、登った日本百名山、出会ったポケモンを公開する個人のコレクションサイト。基本機能の正式仕様は [企画書・実装仕様書](docs/SPECIFICATION.md)、追加の部屋デザインは [ROOM_CONCEPT.md](docs/ROOM_CONCEPT.md) です。

React + TypeScript + Viteによる静的サイトです。ログイン・DB・管理画面・ブラウザ編集機能・閲覧時の外部API通信はありません。実績は9個のTXTで管理し、本人から提供された35の国・地域、35都道府県、日本百名山36座、色違い805種の実績を登録しています。通常色の所持情報・日付・写真は未登録です。

## 開発・確認

Node.js 22.12以上（検証環境：24.19.0）とnpmを使用します。

```bash
npm ci
npm run dev
npm run validate:data
npm run test
npm run test:e2e
npm run test:subpath
npm run build
npm run preview
```

ブラウザテストではChromiumを使用します。ローカルにない場合は `npx playwright install chromium`。Linuxの `/usr/bin/chromium` を自動検出し、それ以外はPlaywright管理のブラウザを使用します。`CHROMIUM_PATH` で指定も可能です。依存OSライブラリがない場合は `npx playwright install --with-deps chromium` を利用してください。

`build` はデータ検証→TypeScript検査→静的ビルドを実行。`dist/` を配信します。既存チェックアウトをそのまま使用できます。

キャラクターの造形確認は、開発サーバーの `/scripts/character-study.html?view=quarter`（斜め45度）で行えます。`view=shallow`（35度）、`profile`（60度）、`reference-side`（75度）、`front`、`side`／`left-side`（左右の真横）、`back`、`rear-quarter`／`rear-quarter-right`（左右の斜め後ろ）で角度を切り替えます。`focus=face` を付けると顔を拡大します。部屋と同じモデルを一定の照明・縮尺で比較する開発用ページで、本番ビルドには含めません。

## 最短の更新方法

1. `public/data/訪問した国.txt` に、実際に訪れた国を1行追加（例：`イタリア`）。保存してページを再読み込みすると件数と地図が変わります。
2. 写真を追加するなら `npm run photos -- /原本/写真.jpg public/photos/countries/italy/01.webp`。
3. `public/data/記録_国.txt` に `イタリア|2025-05|countries/italy/01.webp` の形式で実際の記録を追記。日付が不明なら空欄で構いません。
4. `npm run test:scope -- records && npm run build` を実行して、TXTと写真をGitに反映・再公開。

実績だけなら手順2〜3は不要です。通常色と色違いは別々のTXTへ記入します。色違いTXTは「所持している番号」を保持するため、新たに所持した番号を追記します。今回の未所持リストからの変換と山名の対応は [登録元と集計](docs/RECORDS_IMPORT.md) を参照してください。再訪・再登頂は詳細TXTに同じ項目で複数行を追加します。

[9ファイルの書式・写真追加方法](docs/DATA_FORMAT.md) に全書式とエラー例をまとめています。上記の説明用記録は本番ファイルに入れていません。

## 実装範囲

- キャラクターを映す追従カメラで歩ける3Dの部屋をホームにし、地球儀・ベッド上の日本ポスター・図鑑端末から3つの統合モードを起動。Three.jsによるオリジナルの家具、日光と影、カーテンの動き。
- 提供された画像を参考に、茶色の動物、グレーのパーカー、クリーム色のリュック、しっぽを自作の3D形状で表現。身長は約1.22m。額から頬・口元を一続きの曲面にし、顔に沿う目、厚い耳、折り重なるフード、丸い袖、太ももから絞ったパンツ、薄い靴底を造形しています。リュックは平たい肩ひもと膨らんだ布の形。短い毛・綿・織り目の素材画像もコードで生成します。
- デスクには、本人提供の写真を収めた木製写真立てを配置。背面の金具と支え脚も立体で作っています。[造形・写真の更新方法](docs/ROOM_PHOTO_FRAME.md)。
- ローテーブルにはカメラと、白い縁の付いた10枚の旅行写真を配置。レンズ・背面モニター・ダイヤル、写真の薄い紙と重なりも立体で造形しています。写真からInstagramを新しいタブで開け、選択時に外部リンクであることを表示します。[カメラの配置](docs/ROOM_CAMERA.md) ／ [ポラロイド写真の素材・配置・リンク](docs/ROOM_POLAROIDS.md)。
- 小さな白い小鳥のNPCが部屋を短いジャンプで散歩します。家具・壁・プレイヤーを避け、体はすり抜けず、パンチでは壊れません。メニュー中は停止し、「動きを減らす」では着地して休みます。[小鳥の仕様と確認画像](docs/ROOM_BIRD.md)。
- 提供画像を参考に、薄紫のボブと黄色のリボン、クリーム色のカーディガン、紺の花柄ワンピース、斜め掛けバッグとサンダルの女の子NPCを、主人公・小鳥と同じ自作Three.jsの立体形状で配置。待機中の呼吸とまばたき、衝突判定を持ち、パンチでは壊れません。[造形・配置・更新方法](docs/ROOM_VISITOR.md)。
- ドラッグ／スワイプでキャラクターの周りを360度見回し、画面の向きを基準に移動。PCはWASD／矢印キー、スマホは左下のアナログスティックで、浅く倒すと歩き、大きく倒すと走ります。下へ倒すとカメラ側を向いて手前へ移動し、カメラは向きを保ったまま位置に追従します。Rまたは右上の視点リセットで、現在位置を変えずに背後へ戻せます。
- 通常時は景色に2本指を置き、指の間の場所を基準に0.7〜6倍へ一時的に拡大・縮小できます。3倍までは従来の表示を保ち、3〜3.7倍で主人公が滑らかに消え、その先は景色を遮りません。縮小すると姿が戻ります。操作中は移動・視点回転を止め、片方の指を離すと元のビューへ戻ります。演奏中は無効で、操作ボタンの大きさは変わりません。
- 歩き始めと停止を滑らかにし、歩行から走行への切替でも手足の動きを連続させています。初期位置を部屋の奥へ移し、手前へ歩くための空間を確保。[操作仕様と参考資料の確認状況](docs/CONTROLS.md) にカメラの判断基準をまとめています。
- Space／ジャンプボタンで机・ベッド・ソファに飛び乗り、上を歩けます。F／J／拳ボタンで近くの小物にパンチ。物の直接クリック／タップ、Eで照準先の記録を開く操作にも対応。
- 入口の木製ドアに近づいて正面からパンチすると、ドアが外側へ開きます。開口部を歩いて通り、ページを切り替えずに小さなテラスと部屋を往復できます。開いた状態は同じタブ内で保持し、小物の復元でも閉じません。
- テラスのベースを3秒の滞在で手に取り、「Garden-Party Groove」（EASY／NORMAL／HARD）と、「最終のヒット」（EASY 53音／NORMAL 81音／HARD 114音、スラップ主体の推定編曲）を選べます。縦画面の常設タイムラインと4行×6列（開放弦〜5F）の指板を表示し、音名ボタンの直接タップ・長押し・上下フリック・同一弦の左右スライドで演奏。通常音は同じMIDI音高の別位置も正解です。「奏法練習 · Garden-Party」は曲の終止までの完全版で、EASY 46音／NORMAL 61音／HARD 102音を選べます（初期はNORMAL）。指板とタイムラインは共通の音高グラデーション、主人公は奏法と成功に応じた光・星・花びらで反応します。既存の録音のアタックから継ぎ目のない持続部へ接続し、同じ音声のピッチ変更で発音・スライドします。音声時計に同期して判定・スコア・コンボを更新します。曲終了後はランク・達成率・5判定の件数・最大コンボを表示し、「続ける」で選曲、「やめる」で3Dホームへ戻れます。主人公・部屋・花・楽器と演奏アニメーションは従来のThree.jsシーンを使用。[遊び方・音源・コード構成](docs/ROOM_BASS.md)。
- キャラクターの届く範囲にある陶器・鉢・積み木を壊し、破片を表示。破壊は部屋の小物だけの演出で、TXT・写真・コレクションの実績は変更しません。メニューの「小物を元に戻す」で復元できます。位置・視点・壊した小物は同じタブ内で保持。
- 操作中の大きな見出しと常時表示ラベルを取り除き、記録一覧・設定・操作説明は右上のメニューに集約。
- アイボリー・木・セージ色を基調に、記録画面も明るい配色。Space Groteskをローカル配信。OSの動き抑制設定とメニューの「動きを減らす」設定に対応。
- WebGLが利用できない場合は直接リンクを提供。従来の一覧型トップは `#/index` で利用可能。
- 世界2D SVG地図と遅延読み込みの3D地球儀。同じ訪問ID集合で着色。回転・ズーム・国選択。WebGL非対応時は2Dへ復帰。
- 47都道府県すべての県境と一覧。訪問状態を独立集計。
- 日本百名山100座すべてのマーカー・名称・標高・代表峰。ズーム・移動・検索・一覧から詳細選択。
- 全国図鑑基本種1,025種の番号・日本語名・英語名。番号/名前検索、捕獲済み/未捕獲、世代選択、60種ごとのページング。
- 通常色・色違いを独立管理し、通常のみ／色違いのみ／両方／未捕獲を表示。捕獲種数は和集合。
- 任意精度の日付、再訪・再登頂、複数写真、写真切替と拡大。右パネル／モバイルのボトムシート、Escapeとフォーカス復帰。
- TXTの別名正規化・重複警告・不正日付・未知名・実績不整合・危険なパス・欠損写真のビルド前検証。
- 写真の向き補正・縮小・WebP書き出し・EXIF除去。

## 公開

`base: './'` とハッシュルーティングのため、ドメイン直下でも `/website/` 配下でも配信できます。明示的なパス指定が必要なら `ATLAS_BASE=/website/ npm run build`。

GitHub Pagesの場合：

1. コードをリポジトリに反映する。
2. Settings → Pages → Sourceを **GitHub Actions** にする。
3. `main` にpushするか、Actions → **Publish Personal Atlas** → **Run workflow** を実行する。
4. 以後のTXT・写真更新も `main` に反映すると、検証後に自動で公開する。

ワークフローは `main` へのpushまたは手動実行で起動し、検証・テスト後に `dist/` を配信します。GitHub PagesのSourceは事前に **GitHub Actions** へ設定してください。公開完了はActionsの成功と、deployジョブが出力するURLで確認します。他の静的ホスティングでも `dist/` をアップロードすれば利用できます。

通常のpushと手動実行の既定値 `validation: build` は本番ビルドだけを行います。変更時は差分の影響範囲に必要なテストだけをローカルで実行し、その結果・変更理由・未確認事項を関連資料と検証記録へ同じ変更内で記載します。未変更で依存上の影響もない楽器などのテストを毎回実行しません。既存の範囲が広すぎる場合は対象ファイルを直接指定します。手動公開でテストも行う場合の `build` 以外の `validation` とローカルの `npm run test:scope -- <範囲>` は、同じ [範囲定義](scripts/test-scope.mjs) を参照します。すべての公開で既存の本番ビルド（データ・譜面・ライセンス・TypeScriptの検査を含む）は維持します。

| 範囲 | 使用場面と検証対象 |
|---|---|
| `build`（CIの公開設定） | テストを重複実行せず本番ビルドのみ。通常push・手動公開の既定値。ローカルは `npm run build` |
| `japan` | JAPANの固定地図・移動範囲・情報表示・フィルター・タッチ入力と、日本ポスターからの起動／復元。楽器や他モードのテストは含めない |
| `world-regions` | WORLDの地域分類のみ。分類の単体検証と2D一覧・検索・選択の1ケース |
| `world` | WORLDの描画・操作変更。分類の単体検証とWORLDのブラウザテスト。手動CIではWebKitレイアウトも確認 |
| `visual` | 造形・素材だけの変更。比較画像を別途確認し、部屋描画を検証 |
| `links` | 部屋の入口・外部リンク。スマホ本体、メニュー、代替表示、Instagram、部屋描画 |
| `movement` | 移動・カメラ・ジャンプ・破壊。対応する単体テストと実入力のブラウザテスト |
| `npc` | 小鳥と女の子NPC。移動・衝突・造形とリソース解放の単体テスト、両NPCのブラウザテスト、部屋描画 |
| `outdoors` | 壁・床・出入口。部屋の単体テスト、室内移動・小鳥・ドアとテラスのPC／タッチ操作、部屋描画 |
| `music` | 3秒滞在・3難易度の譜面と押弦なしの採点・スラップ入力・音声・リソース解放、PC／タッチ演奏・ドアとテラス・部屋描画 |
| `records` | TXT・写真のみ。解析・写真処理、公開TXTと画面の照合 |
| `room` / `refactor` | 部屋をまたぐ変更。`room-*.test.ts` と部屋・小鳥・Instagram・テラス・ベース演奏のブラウザテスト |
| `full` | サイト共通処理・マスター・依存関係など。全単体・全ブラウザ・サブパス配信テスト |

`npm run test:scope -- links --list` で対象一覧、`--dry-run` で実行コマンドを確認できます。通常の公開ワークフローではテストを自動で再実行しません。JAPANのUI・共用地図に影響するファイルを変更したpushだけは、別の `Validate changed JAPAN layout` がJAPANのWebKitレイアウト2件を確認します。無関係な変更では起動しません。ローカルで確認できない対象だけ、手動実行で必要な範囲を指定します。`full` は共通基盤など全体への影響がある場合に限って選びます。

## 部屋のコード構成

- [destinations.ts](src/room/destinations.ts)：入口のID・表示名・内部画面・外部URL。3Dオブジェクト、メニュー、WebGL非対応時のリンクで共用。
- [targeting.ts](src/room/targeting.ts)：遮蔽を考慮した対象選択、画面中央／マウスの照準、外部リンクまでの選択保持。UIは `setTargetHovered` でポインター・フォーカス状態を伝えます。
- [furnitureLayout.ts](src/room/furnitureLayout.ts)：家具の位置・寸法。描画、天板上の小物、当たり判定、リンクの注視位置を同じ親座標から導出。ソファなどの段差は別々の当たり判定を維持します。
- [roomArchitecture.ts](src/room/roomArchitecture.ts)：有限の床・壁・窓・天井・テラスの共有形状、ドアのヒンジと開閉、小鳥の室内行動範囲、落下時の帰還先。
- [collision.ts](src/room/collision.ts)／[movement.ts](src/room/movement.ts)／[followCamera.ts](src/room/followCamera.ts)：実物の床と回転を含む立体障害物に対する移動・着地・頭上衝突・カメラの判定。部屋の座標上限や無限の床には依存しません。
- [bassGame.ts](src/room/bassGame.ts)／[bassAudio.ts](src/room/bassAudio.ts)：ベースの滞在時間・MIDI音高と奏法・保持と採点・自動押弦位置、録音の共通時計と直接入力サンプラー。[音源の出典と制作手順](docs/ROOM_BASS_AUDIO.md)。[BassGameHUD.tsx](src/room/BassGameHUD.tsx) の常設タイムラインと24ボタン指板を専用ストアで更新。共通の音高定義は [bassFretboard.ts](src/room/bassFretboard.ts)、表示計算は [bassVisuals.ts](src/room/bassVisuals.ts)。[bassPose.ts](src/room/art/bassPose.ts) から楽器と指先の位置を共通計算します。
- [disposal.ts](src/room/disposal.ts)：取得順の逆順で、所有リソースを一度ずつ解放。途中の初期化失敗でも回収し、借りた写真テクスチャは所有者側で解放します。
- [roomSnapshot.ts](src/room/roomSnapshot.ts)：座標などの診断用属性を直接更新。Reactには画面表示に必要なパンチ状態の変化だけを通知。
- [ブラウザテスト共通ヘルパー](tests/e2e/helpers/room.ts)：保存位置、入室待機、カメラからの投影、描画待機を共用。

## 検証と残る範囲

検証結果は [VALIDATION.md](docs/VALIDATION.md)。キャラクターの部位ごとの変更は [外観の調整記録](docs/CHARACTER_REFINEMENT.md)、[首元の変更前後](docs/screenshots/character-neck-before-after.png)、[フードの変更前後](docs/screenshots/character-hood-before-after.png)、[6方向の確認画像](docs/screenshots/character-comparison.png) にまとめています。PC/360px幅の画面画像は [screenshots](docs/screenshots/)。テスト用実績・画像は通信モックおよび無視対象の `.test-build/` 内だけで使用します。

MUST要件は実装済み。全国図鑑は採用時点の1,025基本種を固定し、将来の追加種はマスター更新が必要です。独立した地図形状のない3地域は一覧と記録で対応し、地図では誤って着色しません。地球儀の主要ライブラリは大きいため3D選択時のみ読み込みます。

屋外は植木鉢・花壇・ベースとアンプのある小さな平坦なテラスです。ドアの回転に人が重なると手前で止まり、離れると開き続けます。低い縁を飛び越えて落下した場合は、実在する床の空いた場所へ戻します。今後は床・壁を追加して歩ける範囲を拡張できますが、斜面・大規模地形の分割読込は未実装です。小鳥は室内だけを散歩し、小物の破片は従来の室内用の簡易演出を使用します。ベース演奏はGarden-Party、奏法練習、最終のヒットのそれぞれ3難易度を選べます。スコア保存は未実装。提供された原曲を既存の音声時計で再生し、指板入力はMIDIサンプラーで発音します。[新曲の元データ・同期調整・運指と奏法の修正](docs/FINAL_HIT_IMPORT.md)。「最終のヒット」はキメを先に保護するEASY 49音／NORMAL 76音／HARD 112音へ再制作し、34〜37秒の反復を全難易度で演奏できます。[キメ・休符の保護と音源照合](docs/FINAL_HIT_PLAYABLE.md)。

SHOULDのフォーム拡張に備えて `speciesId` と `variant` を分離しています。リージョン・姿違い・メガ進化の別集計は初版の対象外です。ポケモン画像は権利未確認のため未使用で、仕様のテキスト図鑑方式を採用。実際の個人記録・写真・正式サイト名・独自ドメインは所有者が追加・変更できます。

公開TXTと写真は誰でも取得可能です。写真は公開用に変換しても、写り込んだ顔・住所・予約情報などの内容は自分で確認してください。原本を公開フォルダに置かず、Git履歴にも残さない運用を推奨します。

## 統合コレクションモード

地球儀・ベッド上の日本ポスター・赤い図鑑端末からWORLD・JAPAN・POKÉDEXを起動します。JAPANは固定地図に県の訪問色と百名山マーカーを表示し、下部（PCでは右側）の一覧だけをスクロールします。山の選択で地図が滑らかに移動し、山名・標高・所属県・登頂状態を小さなラベルへ表示。検索・県切替・パネルサイズ切替・山の詳細モーダルは設けず、3つの登頂フィルターを地図と一覧へ共通適用します。[JAPANの構成・データ・操作](docs/JAPAN_MODE.md)。ブラウザの戻る／モードの戻るで同じ部屋へ復帰し、各モードのフィルターと選択・表示位置を保持します。旧独立URLも利用できます。[構成・状態の所有者・更新ガイド](docs/COLLECTION_MODES.md)。

WORLDは東アジア・東南アジアなど[23の小地域](docs/WORLD_REGIONS.md)で国・地域を整理します。明るい地球儀と地域別一覧を常に同時表示し、一覧内だけをスクロールします。国名・地球儀・2D地図の選択が同期し、日本語ラベルと選択行を表示します。表示リセットでは検索・訪問フィルターを保持します。

部屋の図鑑は隣の写真立てより少し小さい卓上サイズ、日本地図＋百名山のポスターはベッド頭側の壁へ配置しています。地球儀とベッドサイド棚、窓辺の鉢とカーテンの間に余裕を取り、重なりを避けています。[配置・寸法・クリック範囲の更新方法](docs/ROOM_COLLECTION_OBJECTS.md)。
