# WORLDの地域分類

旅行記録を探しやすい大きさに分けるため、国連M49系のNatural Earth `SUBREGION` を基本にする。アジアは東・東南・南・中央・西の5区分。ヨーロッパ、南北アメリカ、アフリカ、オセアニアも同じ粒度で分け、南極・南極周辺を加えた23区分とする。画面は中間の大陸見出しを挟まず、小地域を直接表示する。

## 境界地域と島々

- ロシアは東ヨーロッパ。トルコ・キプロス・ジョージア・アルメニア・アゼルバイジャンは西アジア、カザフスタンは中央アジア。
- イランは元資料と同じ南アジア。「西アジア」と文化・政治上の「中東」は同義として扱わない。
- メキシコは中央アメリカ。カリブ海地域は別区分。仏領ギアナは南アメリカなど、海外領土も所在地を基準とする。
- 原資料の `Seven seas (open ocean)` は地域名として使わない。SGS（サウスジョージア・サウスサンドウィッチ諸島）、ATF（フランス領南方・南極地域）、HMD（ハード島・マクドナルド諸島）は南極・南極周辺、IOT（イギリス領インド洋地域）は東アフリカへ明示的に対応させる。
- 地図形状のないBVT（ブーベ島）は南極・南極周辺、GIB（ジブラルタル）は南ヨーロッパ、UMI（合衆国領有小離島）はミクロネシア。UMIは分散した島々であり、地球儀の代表点ミッドウェーだけで所属を決めたものではない。

国・地域の表示を整理する区分であり、独立・帰属や訪問実績を新たに判定する処理はない。

## 変更・再生成

表示名と順序は `src/maps/worldData.ts`、国ごとの分類と代表点は `src/catalogs/world-view.json`、生成元は `scripts/build-world-view.mjs`。固定Natural Earth 5.1.2のSHAを照合したうえで `node scripts/build-world-view.mjs /固定ソース/world.json` を実行する。今回変更するのは表示用のregionだけで、代表点・既存国ID・地図形状・訪問TXTは変更しない。

分類だけの変更は `npm run test:scope -- world-regions`（単体と一覧の2D連動1件）で確認する。描画や楽器など、変更の影響がない機能を再試験する必要はない。変更理由、例外、確認結果をこの資料と関連資料・検証記録へ同じ変更内で反映する。
