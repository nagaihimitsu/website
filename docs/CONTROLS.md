# 部屋の移動とカメラ

この部屋では、カメラの水平な向きを基準に移動し、キャラクターが進行方向へ向き直ります。下へ倒したときも他の方向と同じ扱いです。

| 操作 | キャラクター | カメラ |
| --- | --- | --- |
| スティック上／W／↑ | 画面の奥へ向いて進む | 位置に追従し、向きは維持 |
| スティック下／S／↓ | こちらへ向き直り、手前へ進む | 位置に追従し、向きは維持 |
| スティック左右／A・D／←・→ | 画面の左右へ向いて進む | 位置に追従し、向きは維持 |
| ドラッグ／スワイプ | その場では向きを変えない | キャラクターの周囲を360度見回す |
| 景色上で2本指を広げる／狭める | 移動・ジャンプ・パンチを止める | 指の間の場所を基準に一時的に拡大／縮小 |
| R／右上の回転矢印 | 位置・向きを変えない | 現在のキャラクターの背後へ戻る |

移動で追従するのはカメラの**位置**です。カメラの**向き**は移動入力だけでは変えません。下入力の途中で自動的に背後へ回り込むと、「手前へ」の方向も変わってしまうためです。見回しと視点リセットは別の操作にしています。自由な部屋の移動を対象にしており、戦闘用のロックオンや後ずさりモードはありません。

スマホは左下のスティックを浅く倒すと歩き、大きく倒すと走ります。斜めも同じ最大速度です。スティックの中心付近には小さな無反応領域を設けています。指を離す、操作がキャンセルされる、メニューを開く、タブを離れる場合は入力を解除します。スティックに1本、景色に1本の指を置くと移動と見回しを同時に操作できます。

通常時に景色へ2本の指を置くと、指の間にある場所を保ちながら0.7〜3倍へ拡大・縮小できます。2本指の中点を動かせば、拡大した景色も指について動きます。カメラの位置・向きと主人公を止め、投影の倍率と表示範囲だけを変えるため、縮小時に壁を抜けません。操作ボタンは拡大しません。片方の指を離すと約0.28秒で元のビューへ戻り、残った指は全て離すまで見回しや記録のタップになりません。「動きを減らす」では即座に戻ります。メニュー・タブ離脱・画面サイズ変更でも解除します。ベースを持っている間はピンチを無効にし、ピンチ中はベースの取得ゲージが進みません。

歩き始めと停止には短い加減速を入れます。速度が変わっても足運びの周期を途中で飛ばさず、手足・胴体・リュックの動きをつなぎます。初期位置を入口側の壁から離し、下入力で手前へ歩くための空間を確保しています。壁や家具がカメラに近づくと撮影距離を短くし、障害物が離れたら距離を戻します。

ジャンプはSpace／右下のジャンプボタン、パンチはF・J／拳ボタン。記録は物をクリック・タップするか、照準を合わせてEで開きます。右上のメニューから各記録へ直接移動することもできます。
