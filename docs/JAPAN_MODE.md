# JAPAN固定地図モード

## 画面と責務

`#/room/mountains` のJAPANは `JapanMode` が選択・登頂フィルター・一覧位置・地図位置を所有する。`CollectionModes` はコンパクトなヘッダーと達成数を表示し、このモードからDetailPanelを開かない。通常の3Dホームの移動・カメラ・展示ID・履歴URLは変更しない。旧 `#/mountains` と `#/japan` の独立記録ページは互換用途で残し、そちらの検索・詳細処理は維持する。

スマートフォンは共通ヘッダーの下を地図55%・一覧45%を基本に分割する。PCと横長の小画面は地図と一覧を左右に並べる。地図・フィルターバーはスクロールせず、`japan-mountain-list` だけが内部でスクロールする。検索欄、県の訪問色・県のみ表示のチェックボックス、最小／中間／最大とハンドルは旧統合コードごと削除した。県の色分けと表示対象の百名山マーカーを常時併記する。

`japanMode.css` はWORLDと同じ生成り・深緑・44px以上の操作領域、控えめな選択行を使用する。WORLDのCSS・状態は変更しない。VisualViewportの高さ・オフセットへCSS変数で追従し、セーフエリア・横向きに対応する。モードを出る際にリスナーとCSS変数を解除する。

## データと選択

百名山番号は既存m001〜m100の数字部、山名・標高・代表座標は既存mountains.jsonを使用する。所属県は既存mountixのregionを保持し、以前の代表峰照合にも使われた固定版hyakumeizan-mapのprefectures_jaで不足する12座を補う。mountainData.tsが表示用mountain-prefectures.jsonを読み、既存県の順序を保ったまま資料に記載された不足県を追加する。地理座標や山塊の範囲から県を推測しない。[所属県の出典確認](MOUNTAIN_AUDIT.md)。

登頂・県訪問の集計は同じArchiveから読み、ヘッダーの分母も既存カタログの長さを使う。TXT・既存マスター・代表峰・標高・県情報・IDは変更しない。すべて／登頂済み／未登頂で、同じ対象集合を一覧・地図へ渡す。選択中の山が対象外になると選択ラベルを消す。フィルターは記録の書き換えを行わない。

一覧とマーカーは共通の選択処理を呼ぶ。地図は対象を中心へ350msで移動し、初期全域表示に対して最低6倍へ拡大する。新しい選択・手動操作で古い補間を中断する。動きを減らす設定では即時移動する。選択マーカーを最後に描画し、山名・標高・所属県・登頂状態のHTMLラベルを球面ではなく地図の位置へ追従させる。ラベルは操作を遮らない。

地図から選んだ場合、一覧自身のscrollToだけで該当行へ移動する。自動スクロールはその選択時の1回だけで、後から手動で一覧を探索する操作を奪わない。写真・日付が実在する場合は一覧内の「登頂記録」を展開し、架空の情報や大きなモーダルを追加しない。

## 地図・ズーム・移動範囲

`Map` の `japanMode` 専用動作を使用する。県境は既存jpn-atlas由来の投影済みGeoJSON、山頂は従来のAzimuthal Equal Area投影を共有する。両者の座標・地図の描画方式を作り直さない。`japanView.ts` が全域フィットと移動制限を計算する。

- 地図SVGを表示領域と同じ縦横比にし、北海道・沖縄を含む全県が初期表示へ収まるよう既存県境の範囲へフィットする。
- ズームは全域フィットを1倍として1〜32倍。ボタン・ホイール・2本指のピンチを共通制御し、ピンチとホイールは操作点を基準に拡大する。
- 移動中心が県ポリゴン内ならその位置を保つ。外側なら最寄りの県境との距離を、地図の短辺の35%に相当する範囲へ制限する。大きな矩形だけで制限して海だけが映る問題を避け、少なくとも県境が表示範囲内に残るようにする。沖縄の離島を含め、既存形状を基準に判定する。
- 広域は山名を最大12件、3倍から35件、8倍から100件まで候補にし、画面端・ズーム操作部・他のラベルと重なる名前を省略する。選択した山の情報ラベルを最優先し、マーカー自体の描画・近傍選択は名前の省略から独立させる。
- マーカーと近傍選択の44px範囲は拡大率によらずCSSピクセルを保つ。複数指・ドラッグを山のタップとして扱わない。
- リセットは地図の全域フィット・選択・ラベルを初期化し、登頂フィルターは保持する。画面回転では地理的中心と相対倍率を維持して新しい縦横比へ合わせる。

WORLDと旧独立ページは `japanMode` を使わず、従来の倍率・移動処理を維持する。非表示時はMapをアンマウントし、表示位置・選択・一覧位置はJapanModeへ保持する。RAF補間、ResizeObserver、wheelリスナーを終了時に解除する。

## 確認と更新

`npm run test:scope -- japan` は日本のデータ・範囲計算の単体と、JAPANのPC／タッチ操作、日本模型からの実物起動・ホームへの復元だけを選ぶ。楽器・WORLD・POKÉDEXのブラウザテストは含めない。複数モードを往復する既存ケースのJAPAN側の期待も新仕様へ更新したが、今回の実行対象とは分ける。

Safari系は `playwright.japan-webkit.config.ts` でJAPANの2Dレイアウト2件を確認する。LinuxのGPUの有無に依存しないようWebGL非対応を模擬する。CDPによる実タッチのピンチ／スワイプはChromiumの専用ケースで確認する。iPhone実機での検証とは区別する。

通常の公開ワークフローは引き続きビルド・公開のみ。別の `Validate changed JAPAN layout` はJAPANのUI・共用地図など指定したファイルに差分があるときだけJAPANのWebKit試験を実行する。無関係な変更での全テストは起動しない。

新しい診断属性は `data-selected-mountain`、`data-japan-zoom`（全域表示に対する倍率）、`data-japan-animating`、`data-pan-x/y`。既存の診断属性や保存キーを変更しない。関連コードを改変するときはこの資料、構成案内、出典資料、検証記録を同じ変更内で更新する。

所属県の再生成は `node scripts/build-mountain-prefectures.mjs /固定資料/hyakumeizan_full.json`。URLとSHAはscripts/catalogs/sources.jsonに固定する。元資料の番号・既存県の包含・代表点の距離も照合する。比較資料の白山・大台ヶ原は粗い座標なので対応確認の距離だけ例外を明示し、表示座標・標高には使用しない。
