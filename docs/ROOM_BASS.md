# テラスのベース演奏

部屋のドアをパンチで開けて外へ出ると、花壇のそばにベースとアンプがあります。[企画書v0.1の原文](BASS_RHYTHM_GAME_SPEC_v0.1.txt) を基に、左手で弦を押さえ、右手で弾くEASYの試作を実装しています。演奏中も同じ3D空間を表示し、左右4段の操作点と譜面を画面に重ねます。

## 遊び方

1. ベースの近くで**連続して5秒**待ちます。円形ゲージが満ちる前に離れると、ゲージが消えて時間もリセットされます。
2. 主人公がベースへ手を伸ばして持ち、演奏位置へ少し移動します。カメラも奏者が見える向きへ滑らかに回ります。
3. **「演奏する」／Space／Enter**で開始します。3拍のカウントダウン中に指定された左の操作点を押さえ、音符が右の判定位置へ届いたら同じ段を弾きます。

左右の段は共通で、上から**G・D・A・E**です。左は押し続けている間だけ有効で、一度タップして離しても保持されません。左だけでは音は鳴らず、正しい左の弦とフレットを押さえたまま、右の対応する弦を弾くと音が出ます。右を押しっぱなしにしても連打にはなりません。

| 操作 | PC | スマートフォン |
|---|---|---|
| ベースまで歩く | WASD／矢印キー | 左下のスティック |
| 演奏を開始 | 「演奏する」／Space／Enter | 「演奏する」をタップ |
| 左手で押さえる | 上から1・2・3・4をホールド | 指定された左の操作点を押し続ける |
| 右手で弾く | 上から7・8・9・0を1回ずつ押す | 左と同じ段の右の操作点をタップ |
| 途中で終える・置く | Esc／「置く」 | 「置く」をタップ |
| 再挑戦 | 結果画面の「もう一度」／Space／Enter | 「もう一度」をタップ |

例えば最初は最下段のE弦・3フレットです。PCなら**4を押したまま0でリズムを刻む**操作になります。スマホでは横持ちで、左親指を指定点へ置いたまま右親指で同じ段を弾きます。縦持ちにも対応します。Space／Enterは画面全体では演奏開始用のショートカットです。フォーカスした操作ボタンにはSpace／Enterによる標準のキーボード操作も用意し、その場合も対応する左の接触が必要です。

フレーズの区切りでは次の弦・フレットを予告します。左のボタンは保持中に指の下で移動せず、離してから次の位置を押します。持っている間は移動・ジャンプ・パンチを止めます。置いた後は一度その場から離れると、再び5秒の滞在で持てます。

メニューを開いた間やタブを非表示にした間は演奏時間と音を停止し、復帰時に続きから進みます。中断時には左の接触を解除するため、再開後は左を押し直してください。

## 譜面と音

初版は**EASYのみ、96 BPM・84音符・30.625秒**のオリジナル譜面です。2小節ずつ6フレーズに分け、各フレーズで左をホールドしながら14回、等間隔の8分音符を弾きます。フレーズ間は約0.94秒空け、弦やフレットを持ち替える時間を確保しています。

判定はPERFECTが前後85 ms、GOODが前後180 ms。右を弾いた瞬間の左の接触と音符の時刻を確認します。左を離している、弦・フレットが違う、タイミングが外れた場合は正しいベース音を鳴らしません。同じ音符を重複して採点せず、空振りは減点とコンボ解除になります。終了時にスコア・精度・最高コンボを表示します。

ベース音と伴奏はWeb Audioで合成します。G／C／Em／Am／D／Gの進行に合わせ、担当するベース音は右手の成功入力で鳴らします。外部の楽曲・録音・サンプルを使わず、追加ダウンロードもありません。近づいただけでは音を鳴らさず、開始操作で音源を起動します。Web Audioが使えない環境では無音でプレイできます。

企画書の**「左を離すとミュートする」は未確定の提案**です。この試作では採用せず、発音済みの音は自然に減衰します。離した後に右だけで弾くことはできません。Normal／Hard、スラップ、追い越し音符、選曲、スコア保存・ランキングは未実装です。演奏によってコレクションのTXTや実績は変更しません。

## 3Dの演奏表現

ベースにストラップを付け、楽器と指先の位置を共通の計算で合わせています。左手は選んだ弦とフレット、右手は弾いた弦へ動きます。ケーブルは楽器のジャックへ追従します。

花は曲の拍に合わせて茎・花・葉を揺らし、成功した音に応じて開花します。成功時には短い花びらと音符の粒子を表示します。「動きを減らす」では踊りと粒子を抑え、次の操作を読みやすくします。

関連範囲だけを検証するコマンドです。

```bash
npm run test:scope -- music
npm run build
```

`music` は左右の弦・フレット対応、実際のホールドと解除、採点・音声・エンジンとモデルの解放を単体テストし、ブラウザでPC／同時タッチの演奏、ドアとテラス、部屋描画を確認します。`npm run test:scope -- music --list` で対象一覧を表示できます。公開ワークフローの手動実行も `validation: music` に対応します。

確認画像：[花壇と楽器](screenshots/bass-garden.png)／[持った姿](screenshots/bass-ready-desktop.png)／[PCの演奏](screenshots/bass-playing-desktop.png)／[縦持ちの演奏](screenshots/bass-playing-mobile.png)／[横持ちの演奏](screenshots/bass-playing-landscape.png)／[演奏と花の動き](screenshots/bass-playing-effects.png)。実行結果は [VALIDATION.md](VALIDATION.md) を参照してください。
