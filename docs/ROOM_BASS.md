# テラスのベース演奏

部屋のドアをパンチで開けて外へ出ると、花壇のそばにベースとアンプがあります。[企画書v0.1の原文](BASS_RHYTHM_GAME_SPEC_v0.1.txt) を基に、ピッキング／スラップする3難易度を実装しています。現在は左の押弦操作を廃止し、主人公が譜面に合わせて自動でフレットを押さえます。演奏中も同じ3D空間を表示し、4段の譜面と右側の操作点を重ねます。

## 遊び方

1. ベースの近くで**連続して3秒**待ちます。円形ゲージが満ちる前に離れると、時間もリセットされます。
2. 主人公がベースへ手を伸ばして持ち、演奏位置へ少し移動します。カメラも奏者が見える向きへ滑らかに回ります。
3. **EASY／NORMAL／HARD**を選び、**「演奏する」／Space／Enter**で開始します。選択は開始前と終了後に変更でき、途中で難易度や譜面は変わりません。
4. 音符が右の判定位置へ届いたら、その段を弾きます。**丸はピッキング、上矢印はスラップ**です。

上から**G・D・A・E**の4段です。押弦ボタンや左手の保持・押し直しは不要です。

| 操作 | PC | スマートフォン |
|---|---|---|
| ベースまで歩く | WASD／矢印キー | 左下のスティック |
| 演奏を開始 | 「演奏する」／Space／Enter | 「演奏する」をタップ |
| 右手でピッキング | 上から7・8・9・0 | 対応する右の操作点を短くタップ |
| 右手でスラップ | Shift＋7・8・9・0 | 対応する右の操作点から素早く上へスワイプ |
| 途中で終える・置く | Esc／「置く」 | 「置く」をタップ |
| 再挑戦 | 結果画面の「もう一度」／Space／Enter | 「もう一度」をタップ |

スマホは右側の4つの操作点だけで演奏でき、縦持ち・横持ちに対応します。スラップは**24px以上、250ms以内**の上方向の動きを検出します。開始した段の弦を保つため、隣の段を横切っても別の弦を弾きません。成立後の指の移動・解放で二重に弾くこともありません。NORMAL／HARDの通常タップは指を離した時点で判定します。長押し・横滑りは通常タップとして扱いません。EASYは従来どおり右に触れた瞬間に弾けます。

Space／Enterは画面全体では開始用です。フォーカスした操作ボタンでは標準のキーボード操作として使え、右ボタンのShift＋Space／Enterはスラップになります。

## 譜面

各段の操作点は右側に1つずつあり、位置は固定です。丸の音符はタップ、上矢印は素早い上スワイプで演奏します。速いスラップ音符は通常音符より後から現れ、追い越すことがありますが、演奏する時刻は曲に固定されています。ミスをしても曲は止まらず、次の音から復帰できます。

ユーザー提供の **Garden-Party Groove** を全難易度で使用します。曲の速さは変えず、実測したベースの音から難易度別の簡略譜面を作っています。[原音・分離・更新方法](ROOM_BASS_AUDIO.md)。

| 難易度 | テンポ | 長さ | 音符 | 中心となる操作 |
|---|---:|---:|---:|---|
| EASY | 約104.7 BPM | 56.14秒 | 41 | ピッキング |
| NORMAL | 約104.7 BPM | 56.14秒 | 49 | ピッキングとスラップ |
| HARD | 約104.7 BPM | 56.14秒 | 54 | 多めのアタック、段の移動とスラップ |

テンポには小さな揺れがあり、録音の実測時刻へ譜面を合わせています。最初に4拍のカウントが入り、実際のベースの休符も残します。同時に2本の弦を要求する譜面はありません。

判定はPERFECTが前後85ms、GOODが前後180ms。弾いた瞬間の時刻、弦の段、ピッキング／スラップの種類を確認します。同じ音符を重複して採点せず、空振りは減点とコンボ解除。終了時にスコア・精度・最高コンボを表示します。

持っている間は移動・ジャンプ・パンチを止めます。置いた後は一度その場から離れると、再び3秒の滞在で持てます。メニューやタブ非表示中は曲と音を停止し、復帰時に続きから進みます。

## 音と演出

提供WAVをローカルで伴奏とベースへ分離し、同じ位置から同期して再生します。成功した譜面音符から次の音符まで、録音のベースが聞こえます。早い成功入力は音符の時刻を待ち、遅い成功入力は残りの区間を再生します。次の音符に失敗した区間は閉じます。従来の合成伴奏や合成ベースは重ねず、カウントインと小さな空振り音だけを合成します。分離音源は推定であり、完全な楽器分離ではありません。[詳細](ROOM_BASS_AUDIO.md)。

近づいたときに音源を先読みし、開始操作で音声を有効にします。曲の準備が終わってからカウントが始まり、読込失敗時は再試行できます。準備中に置く・難易度変更・メニュー表示をしても、後から演奏が始まることはありません。音声中断時には譜面も止め、「音声を再開」で同じ位置から復帰できます。

楽器と指先の位置は共通計算です。左手は譜面の弦・フレットへ自動で移動し、右手はピッキングと親指のスラップを使い分けます。拍に合わせて体と花が動き、成功時には花びらと音符が舞います。スラップ成功時は少し強いアクセントになります。「動きを減らす」では踊りと粒子を抑えます。

ベースは提供された三面図と、その後の演奏姿の見本を基にした立体モデルです。細身で左右非対称の赤茶の木製ボディに、ボディ内部まで伸びる長い指板、22フレット、連続した白いピックガード、3個の丸いノブ、楕円形のペグを配置。裏側には丸いメイプルのネック、4本ねじのネックプレート、ペグの歯車も造形しています。4本の弦・フレット・サドル・指先は同じ実寸法を参照し、12フレットが弦長の半分になる間隔です。

演奏時はネックを耳の高さまで立て、奏者を斜め前から見せます。短く丸い動物の指で支え、平たいチャコール色のストラップが肩を通ってホーン前面とボディ下端の金具につながります。待機中は9フレット付近で支え、曲が始まると実際の譜面のフレットへ移動します。ピッキングは上側のピックアップ付近、スラップは手全体と短い親指で指板の終端付近を叩きます。シールドは白いピックガード下端の出力ジャックにL字プラグで接続し、楽器の動きに合わせてアンプまでのたるみが変わります。スタンド上と保持中の楽器の倍率は共通です。

弾く腕は肩・肘・手首を分け、上腕が体の横へ下がり、短い前腕が楽器の縁を回って弦へ届きます。ピッキング位置をピックアップのネック寄りへ上げ、手を低く伸ばし過ぎない構えにしています。小さな掌に短い指を丸め、袖口から手首を見せます。指の断面は曲がり目でねじれない基準を使い、袖の陰影も曲げた実形状から更新します。

成功した録音区間は次の譜面音符まで継続します。難易度内の選曲、スコア保存・ランキングは未実装です。演奏によってコレクションのTXTや実績は変わりません。

関連する検証だけを実行します。

```bash
npm run test:scope -- music
npm run build
```

`music` は3難易度の譜面、押弦なしの採点、スラップ入力、音声とリソース解放を単体テストし、ブラウザでPC／タッチの演奏、ドアとテラス、部屋描画を確認します。公開ワークフローの手動実行も `validation: music` に対応します。

確認画像：[難易度選択](screenshots/bass-ready-desktop.png)／[NORMAL](screenshots/bass-playing-normal-landscape.png)／[HARD](screenshots/bass-playing-hard-landscape.png)／[EASY](screenshots/bass-playing-desktop.png)／[縦持ち](screenshots/bass-playing-mobile.png)／[横持ち](screenshots/bass-playing-landscape.png)／[演奏と花の動き](screenshots/bass-playing-effects.png)。実行結果は [VALIDATION.md](VALIDATION.md) を参照してください。スマホ操作はChromiumのタッチエミュレーションで確認し、実機Safariの検証は未実施です。

造形の比較には開発サーバーの `/scripts/bass-study.html?view=side` を使えます。`view` は `front` / `quarter` / `side` / `rear` / `back`。既定は9フレットの支持姿勢で、`fret=3` で曲中の低いフレット、`pluck=1&slap=1` でスラップ時の手元も比較できます。各姿勢は補間が落ち着くまで進め、実際のキャラクターと楽器を固定照明で描画します。開発用ページで、本番ビルドには含めません。

腕と指の変更だけを確認するときは `npx vitest run tests/room-bass-pose.test.ts` を使います。実弦との接触、袖・掌・8本の指の実形状と木製ボディ／指板／ネックの非貫通、演奏終了後の元の頂点と法線への復帰を3件で確認します。

楽器単体の正面・背面・側面を同時に比較するページは `/scripts/bass-instrument-study.html` です。寸法は `art/bassPose.ts` の `BASS_DIMENSIONS` に集約し、指板・弦・フレット・演奏する手の位置を連動させています。こちらも開発専用で、本番には含めません。
