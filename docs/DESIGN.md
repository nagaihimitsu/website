# Personal Atlas — Design

基本機能の正式仕様は [SPECIFICATION.md](SPECIFICATION.md)。最新の採用案は「日光の入る部屋を歩き、物から記録を開く」。初期のダークトーン指定から、白い壁・木・布を使った明るい部屋へ変更しています。詳細は [ROOM_CONCEPT.md](ROOM_CONCEPT.md)。

- 部屋の背景は温かい灰白色 `#EEEAE1`、記録画面はアイボリー `#F6F3ED` と墨色 `#313A36`。セージと土色で実績を表します。
- 英字はSpace Grotesk、日本語はOSフォント。ローカル配信し、外部フォントサービスへ通信しません。
- Three.jsの立体的な部屋をホームにします。家具・植物・アバター・スマートフォンはオリジナル形状。壁の地図は既存の実データから描き、件数や色はTXTと連動します。
- キャッチコピーを置かず、サイト名・分類・件数・操作名だけを中心に構成します。地図、図鑑、詳細パネルまで同じトーンに統一します。
- 歩行、ジャンプ、カーテン、選択物の反応、記録へ入るカメラ移動を実装。`prefers-reduced-motion` またはMOTION切替で装飾的な動きを止め、移動・ジャンプの操作は維持します。手動の設定は同じタブ内で保持します。
- 左下の方向パッド、右下のジャンプ、物の直接タップを分離。画面下の直接リンクと `#/index` の一覧型トップも利用できます。部屋からの遷移時は同じタブのsessionStorageに位置と向きを保存します。
- 未達成も地図・一覧から消しません。写真未登録時にダミー写真や空欄カードを置きません。
- 詳細はデスクトップで右パネル、スマホではボトムシート。native dialogでフォーカス制御、Escape・閉じるボタン・背景クリックを提供します。
- 図鑑は1ページ60種、全1,025種へページ送り・検索で到達。通常色・色違いを独立表示。権利未確認のスプライトは使用しません。
- 部屋と3D地球儀は別々に遅延読み込み。部屋のWebGL不可・コンテキスト喪失・初期化エラー時もコレクションへの直接リンクを提供します。地球儀は2Dへ戻します。
- 地図の形状を簡略化して描画負荷を軽減。国・県IDを維持し、ピン座標は変更しません。
- フォーカス表示、コンテンツへ移動するリンク、現在のページを示すナビゲーションを用意。小さな地域には検索・一覧からもアクセスできます。

## 画面確認

`npm run test:e2e` で `docs/screenshots/` に1280px幅、360px幅、部屋の横向き844×390のスクリーンショットを保存。撮影時はアニメーションを完了させます。保存画像は本番の空実績を使用し、テスト用の架空実績と写真はPlaywrightの通信モックまたは `.test-build/` のみに置きます。
