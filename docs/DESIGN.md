# Personal Atlas — Design

基本機能の正式仕様は [SPECIFICATION.md](SPECIFICATION.md)。最新の採用案は「日光の入る部屋で、小さなキャラクターを背中越しに追い、物から記録を開く」。初期のダークトーン指定から、白い壁・木・布を使った明るい部屋へ変更しています。詳細は [ROOM_CONCEPT.md](ROOM_CONCEPT.md)。

- 部屋の背景は温かい灰白色 `#EEEAE1`、記録画面はアイボリー `#F6F3ED` と墨色 `#313A36`。セージと土色で実績を表します。
- 英字はSpace Grotesk、日本語はOSフォント。ローカル配信し、外部フォントサービスへ通信しません。
- Three.jsの立体的な部屋をホームにします。家具・植物・スマートフォンはオリジナル形状。操作キャラクターは提供画像を参考にした茶色の動物で、グレーのパーカー、クリーム色のリュックとしっぽを自作の形状で表現。約1.22mの身長にして家具との間に余裕を持たせます。頭・耳・フードは滑らかな曲面と陰影に整え、短い毛、綿の編み目、リブ、縫い目、リュックの織り目とふくらみを描き分けます。壁の地図は既存の実データから描き、件数や色はTXTと連動します。
- 毛と布の色・凹凸・粗さの画像をコードで生成し、光の当たり方にも素材差を持たせます。細い短毛を輪郭に足し、パーカーの襟・袖・裾には柔らかな折れ目を作ります。繊維をまとめて描画し、遠景では細かな柄を滑らかに縮小して、ざらつきと描画負荷を抑えます。
- 操作画面の大きな見出しと常時表示ラベルを取り除き、部屋を画面いっぱいに描きます。小さな照準・操作アイコンを表示し、記録一覧と設定は右上のメニューへ集約。メニューを開いた間は操作と物理計算を止めます。
- キャラクターの背後を低い角度から追うカメラと、ドラッグ／スワイプによる360度の見回しを実装。移動はカメラの水平な向きを基準にし、下入力ならキャラクターがこちらを向いて手前へ進みます。カメラは位置に追従し、向きは自動で回転させません。壁や家具ではカメラの距離を調整します。Rキー／右上の視点リセットは、キャラクターを動かさずに背後へ視点を戻します。[操作仕様・調査の範囲](CONTROLS.md) も参照してください。
- 初期位置を奥へ移して手前に歩く空間を確保し、急な発進・停止を短い加減速で和らげます。歩く速さに合わせて手足の振り幅と歩調をつなぎ、速度の切替で姿勢が飛ばないようにします。
- 家具へのジャンプと着地、キャラクターのパンチと小物の破壊、カーテン、選択物の反応、記録へ入るカメラ移動を実装。`prefers-reduced-motion` またはメニューの「動きを減らす」設定で装飾的な動きを止め、移動・ジャンプの操作は維持します。手動の設定は同じタブ内で保持します。
- 左下のアナログスティック、右下のジャンプ・パンチ、部屋をドラッグして見回す操作を分離。スティックの浅い入力で歩き、大きな入力で走ります。見回しと移動を同時に操作できます。メニューの直接リンクと `#/index` の一覧型トップも利用できます。同じタブのsessionStorageに位置・視点・壊した小物を保存します。机・ベッドの上の位置も復元します。
- 壊せる物はオリジナルの小物で、破片は短時間で消去します。復元した小物とプレイヤーが重なるときは安全な床へ移し、記録の入口やTXTを壊したり編集したりしません。
- 未達成も地図・一覧から消しません。写真未登録時にダミー写真や空欄カードを置きません。
- 詳細はデスクトップで右パネル、スマホではボトムシート。native dialogでフォーカス制御、Escape・閉じるボタン・背景クリックを提供します。
- 図鑑は1ページ60種、全1,025種へページ送り・検索で到達。通常色・色違いを独立表示。権利未確認のスプライトは使用しません。
- 部屋と3D地球儀は別々に遅延読み込み。部屋のWebGL不可・コンテキスト喪失・初期化エラー時もコレクションへの直接リンクを提供します。地球儀は2Dへ戻します。
- 地図の形状を簡略化して描画負荷を軽減。国・県IDを維持し、ピン座標は変更しません。
- フォーカス表示、コンテンツへ移動するリンク、現在のページを示すナビゲーションを用意。小さな地域には検索・一覧からもアクセスできます。

## 画面確認

`npm run test:e2e` で `docs/screenshots/` に1280px幅、360px幅、部屋の横向き844×390のスクリーンショットを保存。撮影時はアニメーションを完了させます。保存画像は本番の空実績を使用し、テスト用の架空実績と写真はPlaywrightの通信モックまたは `.test-build/` のみに置きます。
