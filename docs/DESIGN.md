# Personal Atlas — Design

正式な機能仕様は [SPECIFICATION.md](SPECIFICATION.md)。ビジュアルは追加要望「ダークトーン・Cool・キャッチコピーを排除」に合わせた個人アーカイブとして構成しています。

- 背景はグラファイト `#090B0D`、文字はシルバー `#E9ECEB`。細い罫線と大きな余白で区切り、実績の色だけを控えめなアクセントにします。
- 英字見出しはSpace Grotesk。大きなATLASとコレクション名、等幅の小さな分類・番号を組み合わせます。日本語はOSの読みやすいフォント。フォントはローカル配信し、外部サービスへ通信しません。
- ホームは実際のNatural Earthデータを正射図法で描いた地球の線画と4コレクション。意味のない地点や架空の記録で装飾せず、実績がゼロでも地理・文字・余白で成立させます。
- キャッチコピーを置かず、サイト名・分類・件数・操作名だけを中心に構成します。地図、図鑑、詳細パネルまで同じトーンに統一します。
- 地球の微小なポインター追従、初回のフェード、カードのホバーに動きを限定。自動回転やスクロールの乗っ取りはありません。`prefers-reduced-motion` では動きを止めます。
- ホームはPCで2列、スマホで1列。モバイルの地球は意図的に右側をクロップし、本文や操作部分の横はみ出しを防ぎます。
- 未達成も地図・一覧から消しません。写真未登録時にダミー写真や空欄カードを置きません。
- 詳細はデスクトップで右パネル、スマホではボトムシート。native dialogでフォーカス制御、Escape・閉じるボタン・背景クリックを提供します。
- 図鑑は1ページ60種、全1,025種へページ送り・検索で到達。通常色・色違いを独立表示。権利未確認のスプライトは使用しません。
- 操作用の3D地球儀のみ動的import。WebGL不可・コンテキスト喪失・初期化エラーは2Dへ戻します。
- 地図の形状を簡略化して描画負荷を軽減。国・県IDを維持し、ピン座標は変更しません。
- フォーカス表示、コンテンツへ移動するリンク、現在のページを示すナビゲーションを用意。小さな地域には検索・一覧からもアクセスできます。

## 画面確認

`npm run test:e2e` で `docs/screenshots/` に1280px幅と360px幅のスクリーンショットを保存。撮影時はアニメーションを完了させます。保存画像は本番の空実績を使用し、テスト用の架空実績と写真はPlaywrightの通信モックまたは `.test-build/` のみに置きます。
