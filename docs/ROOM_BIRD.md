## 今回の外観調整（2026-10-18）

基準コミット `04efcdb` と所有者の正面・横・背面画像を比較し、4方向の描画を繰り返して調整しました。

- **翼**：横に置いた楕円体から、胴の曲面へ巻き付く形に再構成。正面の張り出しを抑え、横では丸い前肩から後ろへ広がり、背面では両翼の間に白い背中が残るよう調整しました。上部の明るいグレーと、斜めに切り替わる暗い羽先も修正。
- **白い体**：頭・腹・底を接線が連続する曲線でつなぎ、下腹の膨らみと丸い底を調整。首の継ぎ目はありません。
- **顔**：目をわずかに横へふくらませ、新しい胴の表面に配置。くちばしは幅と根元の厚みを増やし、前端へ丸く細まる形にしました。
- **尾・足**：尾を短く厚くし、足の円周と指のカーブを滑らかに。グレー・黄・茶の色も比較して調整しました。
- **表面**：マットな体・翼・尾・足に、小鳥専用の柔らかな拡散反射を適用。部屋の日光でも硬い明暗境界が出にくくしています。目とくちばしの光沢反射は従来の計算です。

[変更前後の三方向](screenshots/bird-before-after.png) は、上段が `04efcdb`、下段が今回のモデルです。両方を同じカメラ・同じ柔らかいスタジオ照明で撮り直しました。比較用照明の変更は開発ページだけに適用しています。

実際の部屋の照明でも [正面](screenshots/bird-room-close-front.png)・[横](screenshots/bird-room-close-side.png)・[後ろ](screenshots/bird-room-close-back.png) を近接撮影しました。これは造形確認用のカメラであり、プレイ中のカメラ設定には追加していません。

## 動きと当たり判定

`src/room/birdMotion.ts` が床の空いた場所へ行き先を選びます。通常は約25〜48cmずつ、高さ約10〜13.5cmの小さなジャンプで進み、間に短い休憩や長めの立ち止まりを挟みます。家具の際では短い進路も探します。壁や有効な家具を横切る経路は選びません。

プレイヤーは小鳥の当たり判定を通過できず、小鳥もプレイヤーへ割り込みません。跳ねている間も体が重ならないよう、当たり判定はジャンプの範囲を含む幅42cm・高さ62cmです。小鳥の上にプレイヤーがいるときも横移動を止めます。

小鳥は壊せる物の一覧に登録しません。パンチやクリックによるダメージ・破壊・吹き飛びはありません。壊した小物を復元した際に位置が重なる場合は、近くの空いた床へ配置し直します。記録画面から部屋へ戻った際も、プレイヤーの保存位置を避けて出現します。

メニュー表示中・タブ非表示中は部屋と一緒に停止します。「動きを減らす」では進行中のジャンプを着地まで終えて休み、装飾的な揺れとまばたきも停止します。設定を戻すと滑らかに再開します。

## 検証

今回の外観修正では、次だけを確認しました。

- 固定照明の4方向を繰り返し比較。最終版を正面・真横・背面・斜めで撮影。
- 部屋の照明の近接3方向と、本番ビルドのPC／390px幅表示を確認。ページ例外・シェーダーエラーなし。
- 静的監査1回：全頂点属性・行列が有限、インデックスと法線が正常。二重disposeでも各リソースの破棄は1回。
- 11メッシュ、39,536三角形、形状6・材質7。静止寸法は約32.0×45.0×32.2cmで、既存の幅42cmの当たり判定内。
- `npm run build` 成功：データ検証・ライセンス生成・TypeScript・Viteビルド。部屋JSは93.43KB（gzip 37.24KB）。
- 公開ワークフローは `validation: visual` を使用し、既存の部屋描画テスト1件と本番ビルドに限定。

移動・ジャンプ・パンチなどの操作コードは変更していません。追加時に成功した小鳥単体テスト7件・ブラウザテスト2件は今回再実行していません。
