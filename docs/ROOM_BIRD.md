# 部屋の小鳥

所有者から提供された正面・横・背面の参考画像をもとに、自作のThree.js形状で制作しました。外部モデル・画像・依存パッケージは追加していません。

## 見た目

- 全高約45cm。操作キャラクターより小さい、頭と胴が連続した丸い白い体。
- 小さな黒茶色の目、黄色い丸いくちばし、濃い羽先を持つグレーの翼、短い尾、茶色の三本指の足。
- 短いジャンプに合わせた体の伸縮、足の引き上げ、小さな羽の揺れ、時折のまばたき。
- 正面・真横・背面・斜めで見比べ、羽の胴への沿い方と位置、尾の長さを調整。部屋の照明と390px幅でも確認。

## 動きと当たり判定

`src/room/birdMotion.ts` が床の空いた場所へ行き先を選びます。通常は約25〜48cmずつ、高さ約10〜13.5cmの小さなジャンプで進み、間に短い休憩や長めの立ち止まりを挟みます。家具の際では短い進路も探します。壁や有効な家具を横切る経路は選びません。

プレイヤーは小鳥の当たり判定を通過できず、小鳥もプレイヤーへ割り込みません。跳ねている間も体が重ならないよう、当たり判定はジャンプの範囲を含む幅42cm・高さ62cmです。小鳥の上にプレイヤーがいるときも横移動を止めます。

小鳥は壊せる物の一覧に登録しません。パンチやクリックによるダメージ・破壊・吹き飛びはありません。壊した小物を復元した際に位置が重なる場合は、近くの空いた床へ配置し直します。記録画面から部屋へ戻った際も、プレイヤーの保存位置を避けて出現します。

メニュー表示中・タブ非表示中は部屋と一緒に停止します。「動きを減らす」では進行中のジャンプを着地まで終えて休み、装飾的な揺れとまばたきも停止します。設定を戻すと滑らかに再開します。

## 検証

- 小鳥に絞った単体テスト7件：家具・薄い障害物・壁・人との衝突、120秒の移動、安全な出現、上にプレイヤーがいる状態、動き抑制、2／15／60FPSの経路一致。
- 小鳥のブラウザテスト2件：ジャンプ移動、メニュー中の停止と再開、すり抜け防止、パンチ無効。
- 固定照明4方向と実際の部屋のPC／スマホ表示。ページ例外なし。
- 11メッシュ、25,552三角形、形状6・材質7。形状とアニメーションの値が有限であること、二重disposeでもリソース解放が1回であることを確認。

造形は `src/room/art/bird.ts`、表示・当たり判定への接続は既存の `roomScene.ts` と `roomEngine.ts`。比較用の `/scripts/bird-study.html?view=front` は開発専用で、本番ビルドには含みません。
