# 部屋の小鳥

所有者から提供された正面・横・背面の参考画像をもとに、自作のThree.js形状で制作しました。外部モデル・画像・依存パッケージは追加していません。

- 全高約45cm。操作キャラクターより小さい、頭と胴が連続し、背中側にふくらみのある白い体。
- 小さな黒茶色の目、黄色い丸いくちばし、濃い羽先を持つグレーの翼、短い尾、茶色の三本指の足。
- 短いジャンプに合わせた体の伸縮、足の引き上げ、小さな羽の揺れ、時折のまばたき。
- 正面・真横・背面・斜めで見比べ、羽の胴への沿い方と位置、尾の長さを調整。部屋の照明と390px幅でも確認。

## 今回の外観調整（2026-10-18：背中・丸目・先端）

基準コミット `03d6c11` と所有者の正面・横・背面画像を比較しました。横顔を優先し、複数回の描画で次を調整しています。

- **白い胴**：前後対称の回転体から、背中〜腰へ張り出す形へ変更。頭の中心より胴の中心が約1.95cm後ろにあり、胸より背中側の膨らみが大きくなっています。白い体そのものを変形し、羽を大きくして膨らみを代用していません。
- **羽の載り方**：白い胴と同じ曲面計算を使い、背中の膨らみの上へ沿わせました。
- **頭と目**：頭幅を約4%広げ、目を縦長から真円に近い形に。新しい顔の表面へ位置を合わせ直しました。
- **くちばし**：根元に厚みを残し、横から先端へ絞った形へ。最初の案は尖りすぎたため、先端に丸みを戻しました。
- **尾**：楕円の塊から、根元が広く後ろへ薄くなる羽へ変更。横では寝た形、背面では下中央へ丸くすぼむ形にしました。

[変更前後の三方向](screenshots/bird-before-after.png) は、上段が `03d6c11`、下段が今回のモデルです。カメラ・照明・縮尺は同じです。[白い体だけの側面](screenshots/bird-white-profile.png) は形状確認のため羽と尾を一時的に非表示にした描画で、公開サイトでは通常どおり表示されます。

部屋の照明でも [正面](screenshots/bird-room-close-front.png)・[横](screenshots/bird-room-close-side.png)・[後ろ](screenshots/bird-room-close-back.png) を近接撮影しています。これは造形確認用カメラで、プレイ中のカメラ設定には追加していません。

前回の翼の再構成・柔らかな拡散反射は維持しています。[前回の比較画像](https://github.com/nagaihimitsu/website/blob/03d6c11/docs/screenshots/bird-before-after.png) は `04efcdb` から `03d6c11` への変更です。

## 動きと当たり判定

`src/room/birdMotion.ts` が床の空いた場所へ行き先を選びます。通常は約25〜48cmずつ、高さ約10〜13.5cmの小さなジャンプで進み、間に短い休憩や長めの立ち止まりを挟みます。家具の際では短い進路も探します。壁や有効な家具を横切る経路は選びません。

プレイヤーは小鳥の当たり判定を通過できず、小鳥もプレイヤーへ割り込みません。跳ねている間も体が重ならないよう、当たり判定はジャンプの範囲を含む幅42cm・高さ62cmです。小鳥の上にプレイヤーがいるときも横移動を止めます。

小鳥は壊せる物の一覧に登録しません。パンチやクリックによるダメージ・破壊・吹き飛びはありません。壊した小物を復元した際に位置が重なる場合は、近くの空いた床へ配置し直します。記録画面から部屋へ戻った際も、プレイヤーの保存位置を避けて出現します。

メニュー表示中・タブ非表示中は部屋と一緒に停止します。「動きを減らす」では進行中のジャンプを着地まで終えて休み、装飾的な揺れとまばたきも停止します。設定を戻すと滑らかに再開します。

## 検証

今回の外観修正では、次だけを確認しました。

- 固定照明の4方向を繰り返し比較。最終版を正面・真横・背面・斜めで撮影。
- 部屋の照明の近接3方向と、本番ビルドのPC／390px幅表示を確認。ページ例外・シェーダーエラーなし。
- 静的監査1回：全頂点属性・行列が有限、インデックスと法線が正常。上下の極で形状が連続し、各極は1頂点へ溶接。二重disposeでも各リソースの破棄は1回。
- 11メッシュ、40,976三角形、形状7・材質7。水平半径は最大20.5cmで、任意の向きでも既存の幅42cmの当たり判定内。
- `npm run build` 成功：データ検証・ライセンス生成・TypeScript・Viteビルド。部屋JSは93.97KB（gzip 37.45KB）。
- 公開ワークフローは `validation: visual` を使用し、既存の部屋描画テスト1件と本番ビルドに限定。

移動・ジャンプ・パンチなどの操作コードは変更していません。追加時に成功した小鳥単体テスト7件・ブラウザテスト2件は今回再実行していません。

造形は `src/room/art/bird.ts`、表示・当たり判定への接続は既存の `roomScene.ts` と `roomEngine.ts`。比較用の `/scripts/bird-study.html?view=front` は開発専用で、本番ビルドには含みません。外部モデル・画像・依存パッケージの追加はありません。
