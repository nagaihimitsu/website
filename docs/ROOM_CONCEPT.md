# 3Dの部屋 — 実装仕様

ステータス：ユーザー採用案と追加の操作要望に基づく実装仕様。日光の入る部屋、写真立ての隣の小型図鑑端末を入口とし、キャラクターを映しながら追う三人称のカメラへ変更。

## 体験と造形

トップページを歩ける一室として作り、家具や持ち物から既存の3つの統合コレクションモードを開く。昔のFlashサイトにあった探索性をWebGLで実現する。提供画像は家具の配置と間取りの参考に使い、線画の表現は再現しない。

美術は、白い壁、木、布、日光を使った立体的な小さな部屋。形状は少し整理し、素材・陰影・触れた反応で質感を作る。カメラはキャラクターの背中越しの低い位置から追従し、ドラッグ／スワイプで上下と周囲360度を見回す。大きな見出しや常時表示の入口ラベルを操作画面に重ねない。窓辺にベッド、側面にソファ、机と棚を記録の入口にする。

操作するキャラクターは、ユーザー提供の正面・側面・背面画像を参考に自作する。茶色の丸い耳の動物、星の光が入った目、グレーのパーカー、クリーム色のリュック、濃いパンツとしっぽを立体化する。身長は約1.22mに抑え、以前の約1.5mのプレイヤーより小さくして家具や部屋との間に余裕を作る。移動・ジャンプ・パンチを身体の動きで伝える。

室内には小鳥に加え、提供画像の女の子NPCを配置する。薄紫のボブ、黄色のリボン、クリーム色のカーディガン、紺の花柄ワンピース、茶色の斜め掛けバッグとサンダルを、自作の立体メッシュとコード生成素材で表現する。空いた床で静かに立ち、呼吸とまばたきをする。主人公・小鳥と同じシーンの照明と影を使い、当たり判定を持つ。メニュー中は部屋とともに停止し、「動きを減らす」では静止する。[造形・配置の変更案内](ROOM_VISITOR.md)。

額・頬・口元・顎を一続きの曲面にし、目は顔に沿う浅いレンズにする。耳は厚みのある裏側、丸い縁、くぼんだ内側を持つ。輪郭に短い繊維を添え、近づいたときに毛並みが見える程度の細かな凹凸に抑える。パーカーは頭に沿う大きなフード、丸みのある袖、低い裾とリブ、ポケットの縫い目を持つ。パンツは太ももを太く、裾へ向かって絞り、靴には薄い明色の底を付ける。リュックは膨らんだ布の形に平たい肩ひもを掛ける。毛・綿・キャンバス地・目の光沢を描き分け、素材の画像はすべてコードで生成する。

正面と斜めの追加参考画像を併用する。額・左右の頬・短く出た口元・中央の顎を、それぞれ異なるふくらみが連続する曲面として造形する。目の周囲は局所的になだらかな面にして、斜めから見たときに目が顔の側面へ回り込みすぎないようにする。鼻は丸い逆三角形、口は二つの丸い弧。大きい五芒星は目の内上側、小さい四芒星は外下側に左右対称で配置し、耳元の毛束は広い根元から柔らかい先端へつなげる。フードは中央の顎が見えるV字の折り返しにする。

紐は細かな綿の編み目、たわみ、柔らかな結び目と短い先端を持つ。手は袖口からのぞく小さなミトン形で、親指と掌を一体の曲面にする。リュックは背中に接した膨らみ、表面に沿う縫い目、肩から脇へ回る厚い肩ひもを持つ。靴の白いつま先は、丸いアーチ状の境界で黒い甲につなげ、薄いソールと連続させる。

歩き始めと停止に短い加減速を入れ、歩行から走行へ変わるときも足運びを連続させる。ジャンプと着地の姿勢もつなぎ、パンチ後は動作中の姿勢へ滑らかに戻す。初期位置は後ろ壁から離して、下入力で手前へ歩き出す余地を確保する。

| 入口 | 記録画面への動き |
|---|---|
| 部屋奥の地球儀 | カメラが寄りWORLDへ。地球儀／2D地図と地域別一覧を表示 |
| ベッド頭側の壁の日本ポスター | 壁面の正面へ接近し、県訪問色＋百名山100座の固定地図と一覧を表示 |
| 写真立ての隣の小型図鑑端末 | 写真立てより少し小さい端末へ接近しPOKÉDEXへ。通常色・色違いを独立表示 |

現在の図鑑の縮小率、ポスターの配置、地球儀とベッドサイド棚の間隔・更新方法は [コレクション展示](ROOM_COLLECTION_OBJECTS.md) に記載する。地球儀は部屋奥のほぼ中央へ寄せ、台座が棚へ食い込まないようにする。

カーテン、日光、カメラ、触れた物に動きを配置する。パンチはキャラクターの腕で表現する。部屋に戻ると位置・視点・壊した小物の状態を復元する。実際に登録された写真や実績だけを飾り、架空の登頂記念品や旅行写真を置かない。遠くの入口も直接タップ可能にする。

現行のWORLD入口は部屋奥の地球儀です。JAPANはベッド頭側の壁に額装し、クリック対象と接近時の注視点をポスターへ追従させます。図鑑は机の写真立ての隣で台座ごと縮小し、机面に合わせて高さを調整します。

## 操作

- スマホ：左下のアナログスティックで移動。浅く倒すと歩き、大きく倒すと走る。右側をスワイプして見回しながら移動できる。右下のジャンプボタンを1回タップして机・ベッド・ソファの上に着地し、拳ボタンで近くの小物を壊す。物は直接タップして開く。
- PC：WASD／矢印キーで移動、ドラッグで360度見回す。Spaceでジャンプ、F／Jでパンチ、クリックまたはEで記録を開く。キーボードで記録画面へも到達できるようにする。
- 移動方向はカメラの水平な向きを基準にする。下へ倒すとキャラクターがカメラ側へ向き直り、手前へ歩く。カメラは位置に追従し、水平な向きは維持する。移動だけでキャラクターの背後へ回り込まない。見回すだけではキャラクターの向きと位置を変えない。
- Rキーまたは右上の視点リセットボタンで、今いるキャラクターの背後へカメラを戻す。位置やジャンプ状態は変えない。
- カメラはキャラクターを追い、壁や家具の内側に入らないよう距離を調整する。キャラクター自身も家具の側面・上面・下面・壁・天井に当たり判定を持ち、上から着地する、端から落ちる、頭をぶつける動きを扱う。
- 画面全体のタップをジャンプに割り当てると物の選択と衝突するため、ジャンプ操作の領域を分ける。二段ジャンプや足場攻略は入れず、閲覧に操作技術を要求しない。
- 動きを軽減する設定と、既存のコレクションに直接入る導線をメニュー内に用意する。メニューを開くと操作を停止する。
- パンチはキャラクターの前方の届く範囲に当たり、遮蔽物を通過しない。陶器・鉢・積み木などの小物に破片の演出を付ける。メニューから復元でき、TXTや写真、実績の件数は変更しない。

## 実装方針

React／TypeScript／Vite、静的ホスティング、TXT解析・マスターは継続する。既存依存のThree.jsで部屋を構成する。家具とキャラクターはローカルの形状、壁の地図とスマートフォン画面はCanvasで生成したテクスチャを使い、外部アセットを取得しない。原神・ゼルダ・3Dマリオは操作感の参考とし、それらのキャラクター・モデル・音源・画面素材を使用しない。新たな依存ライブラリは追加しない。直射光と環境光、シャドウマップ、端末別の描画品質を使用する。物を選んだ後の地図・図鑑・写真は既存の記録画面を接続する。ログイン・DB・管理画面は追加しない。

一室、三つのコレクション入口、操作キャラクター、アナログ移動、360度の見回し、追従と視点リセット、家具へのジャンプ、パンチ、破壊と復元、画面遷移を実装する。PCとスマホの縦横画面で操作と見た目を確認する。

操作の採用理由と調査の範囲は [CONTROLS.md](CONTROLS.md) に記録する。任天堂とHoYoverseの公式ページは環境の通信制限により取得できておらず、各ゲーム固有のカメラ挙動を検証済みとは扱わない。本サイトではユーザーの希望に合わせて、移動と見回しを独立させる仕様を採用する。
