# 3Dの部屋 — 実装仕様

ステータス：ユーザー採用案と追加の操作要望に基づく実装仕様。日光の入る部屋、iPhone風スマートフォンの入口を継続し、見下ろす視点から一人称の主観視点へ変更。

## 体験と造形

トップページを歩ける一室として作り、家具や持ち物から既存の4コレクションを開く。昔のFlashサイトにあった探索性をWebGLで実現する。提供画像は家具の配置と間取りの参考に使い、線画の表現は再現しない。

美術は、白い壁、木、布、日光を使った立体的な小さな部屋。形状は少し整理し、素材・陰影・触れた反応で質感を作る。カメラは床から約1.5mの目線に置き、ドラッグ／スワイプで上下左右を見回す。大きな見出しや常時表示の入口ラベルを操作画面に重ねない。窓辺にベッド、側面にソファ、机と棚を記録の入口にする。

| 入口                           | 記録画面への動き                                                       |
| ------------------------------ | ---------------------------------------------------------------------- |
| 壁の大きな世界地図             | カメラが寄り、訪問国の地図を全画面表示。2D／3D切替を継続               |
| 机の横の日本地図               | 47都道府県の訪問記録へ                                                 |
| 棚の山岳模型と登山ノート       | 百名山100座の地図と登頂記録へ                                          |
| 机の上のiPhone風スマートフォン | 画面が明るくなり、カメラが寄って全国図鑑へ。通常色・色違いの件数を表示 |

カーテン、日光、カメラ、触れた物に動きを配置する。拳はパンチ中だけ表示する。部屋に戻ると位置・目線・壊した小物の状態を復元する。実際に登録された写真や実績だけを飾り、架空の登頂記念品や旅行写真を置かない。遠くの入口も直接タップ可能にする。

## 操作

- スマホ：左下の方向パッドを押して移動。右下のジャンプボタンを1回タップしてジャンプし、机・ベッド・ソファの上に着地できる。拳ボタンで近くの小物を壊す。物は直接タップして開く。
- PC：WASD／矢印キーで移動、ドラッグで見回す。Spaceでジャンプ、F／Jでパンチ、クリックまたはEで記録を開く。キーボードで記録画面へも到達できるようにする。
- 画面全体のタップをジャンプに割り当てると物の選択と衝突するため、ジャンプ操作の領域を分ける。
- カメラはプレイヤーの目線に追従する。家具の側面・上面・下面・壁・天井に当たり判定を持たせ、上から着地する、端から落ちる、頭をぶつける動きを扱う。
- 二段ジャンプや足場攻略は入れず、閲覧に操作技術を要求しない。
- 動きを軽減する設定と、既存のコレクションに直接入る導線をメニュー内に用意する。メニューを開くと操作を停止する。
- パンチは2m以内の照準先に当たり、遮蔽物を通過しない。陶器・鉢・積み木などの小物に破片の演出を付ける。メニューから復元でき、TXTや写真、実績の件数は変更しない。

## 実装方針

React／TypeScript／Vite、静的ホスティング、TXT解析・マスターは継続する。既存依存のThree.jsで部屋を構成する。家具はローカルの形状、壁の地図とスマートフォン画面はCanvasで生成したテクスチャを使い、外部アセットを取得しない。直射光と環境光、シャドウマップ、端末別の描画品質を使用する。物を選んだ後の地図・図鑑・写真は既存の記録画面を接続する。ログイン・DB・管理画面は追加しない。

一室、四つの入口、移動、見回し、家具へのジャンプ、パンチ、破壊と復元、画面遷移を実装する。PCとスマホの縦横画面で操作と見た目を確認する。
