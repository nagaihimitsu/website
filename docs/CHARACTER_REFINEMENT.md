# キャラクター外観の調整記録

## 今回：茶色の首元と紐の細部

比較基準は公開済みコミット [`7289c00`](https://github.com/nagaihimitsu/website/tree/7289c00d5d8cdad49592cded14f3775f98a48e02) です。参考図で顎の下に見える茶色の毛に対し、実装ではグレーの裏地が開口を塞いでいました。首元を主な修正対象とし、同じ角度で4段階の比較を行っています。

[首元の変更前後](screenshots/character-neck-before-after.png) ／ [最新の6方向](screenshots/character-comparison.png)

| 比較した部分 | 採用した修正 |
|---|---|
| 首元のグレーの帯 | フード中央を塞いでいた裏地の形状を取り除いた |
| 顎と首のつながり | 頭の最下部の曲面を首まで連続させ、頭と同じ茶色の毛がフードの開口から見える形にした |
| 首の上側の境目 | 別の首パーツを足す方式をやめ、頭の曲面を共有。水平な継ぎ目が出ないようにした |
| 顎の下の陰影 | 変形の始まりと終わりで曲率が急変しないように補間し、段状の陰影を和らげた |
| 横からの首元 | 首の下端をフードと胴体の内側へ収め、顎の前に別の膨らみが出ない形にした |
| パーカーの紐の太さ | 半径を約11％増やし、細い針金状に見える傾向を抑えた |
| 紐の垂れ方 | 均一な直線から、中央がわずかに外側へ膨らむ緩いカーブへ変更した |
| 紐の結び目 | 幅・高さ・厚みを約10％増やし、新しい紐の経路へ合わせた |
| 結び目の下の短い先端 | 太さと長さを微調整し、結び目とのつながりを整えた |
| 目の反射 | 小さな反射光をわずかに上へ移し、強度を約11％抑え、白い星との重なりを軽減した |

最初の首パーツでは茶色の上端に水平な線が残ったため、採用していません。耳の付け根を引き込む2案、肩紐の下側のカーブを変える複数案も比較しましたが、斜め後ろの耳の輪郭や正面の肩紐の見え方を損ねるため、今回の完成版には含めていません。

首元の見え方は修正しましたが、フードの折れの均一さや正面の肩紐には参考図との差が残っています。形状・材質はコードで生成しており、新しい外部モデルや画像は追加していません。

今回の実装は [characterHead.ts](../src/room/art/characterHead.ts)、[characterHood.ts](../src/room/art/characterHood.ts)、[characterMaterials.ts](../src/room/art/characterMaterials.ts) の3ファイルです。検証結果は [VALIDATION.md](VALIDATION.md) に記録しています。操作系の全テストは繰り返していません。

## 前回：フードと全身の細部（7289c00）

以下は前回の調整記録です。個別の全身画像は最新版に更新し、フードの変更前後画像は当時のものを保持しています。

比較基準は公開済みコミット [`6705c65`](https://github.com/nagaihimitsu/website/tree/6705c65dcf7a0f785ae72e8600c171d4ef87e2f6) です。今回提示された正面・横・後ろ・斜め前の理想図に対し、特に横から見たフードを優先して調整しました。以下は今回コードへ反映した変更であり、以前の修正や、比較中に挙げた未採用の案を含めていません。

[多方向の確認画像](screenshots/character-comparison.png) ／ [フードの変更前後](screenshots/character-hood-before-after.png)

### フード：断面と布のつながり

基準版では、側面に細い溝が走り、前の折り返しが途中で終わる別部品として見えていました。横からは後方へ張り出した硬い形に見えるため、折り返しを足す調整から、フード本体の断面を作り直す方法へ変更しました。

| 比較した部分 | 今回の調整 |
|---|---|
| 側面の厚み | 明示的な曲線で断面を定義し、上側の丸い折り返しと下側の膨らみを一続きの面にした |
| 二つの膨らみの間 | 細く刻んだ溝を、幅のある浅いくぼみに置き換えた |
| 前の折り返しの終端 | 側面で途切れて見える独立した左右の部品を除き、本体の曲面へ統合した |
| 顎から頬へ上がる線 | 中央が低く、頬へ向かって滑らかに上がる輪郭へ調整した |
| 側面後方の張り出し | 後ろへ長く伸びる奥行きを抑え、首とリュック上部へ近づけた |
| 後ろの下端 | 両肩側を持ち上げ、中央だけが丸く下がる形にした |
| 後ろ中央の断面 | 側面と同じ溝を一周させず、中央では膨らみがつながる断面へ補間した |
| フードとリュックの重なり | フードの下端とリュック上部の丸みを合わせて調整し、上部の肩紐が露出しすぎる箇所を詰めた |
| 紐の出口 | 独立した折り返し部品ではなく、本体の折り返し面から紐が出る位置へ移した。穴の向きもその面に合わせた |
| 内側の材質境界 | 新しい断面に合わせ、外布と内布を割り当てる範囲を調整した |

途中の形では、側面の折れが深すぎる、後ろの中央が平らになる、リュックの上端や肩紐が見えすぎる、といった差が残ったため、正面だけで決めず横・背面へ戻って調整を繰り返しています。

| 耳前の毛束の位置 | 三つの毛束の先端を少し上・外側へ振り、段差と間隔を調整した |

### 比較方法と残る差

固定した照明とカメラで同じモデルを繰り返し描画し、正面、斜め前、参考図に近い75度、真横、後ろ、左右の斜め後ろを比較しています。75度の画像と真横の画像を分けることで、参考図の見え方と、形状のつながりの両方を確認しています。

フードの折れ、目の反射、ポケットと靴の境界などは改善しましたが、理想図の完全な再現ではありません。フードの折れにはまだ規則的な部分があり、実際に布が重なったときの細かな張りや不均一な厚みには差があります。正面の肩紐の見え方や、服のごく局所的な陰影も参考図と一致していません。

形状・布の模様・反射用の画像はコードで生成しています。外部のモデルや素材画像は追加していません。参考画像は造形を比較するために使用しており、公開ページに画像を貼り付けて置き換える実装ではありません。
