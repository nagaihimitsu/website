# 3Dコレクションモード

## 構成

- `RoomHome` は入室中ずっと同じ `RoomEngine` を所有する。`CollectionModes` がモードの表示・履歴・詳細を担当し、`Collection` を旧独立URLと共用する。iframeやページ読み込みは使わない。
- `RoomEngine.open` は入力をクリアし、500msで展示へ接近する。`closeCollection` は遷移ロックを解除し、保存したカメラを復元する。歩行座標・視線・小物・ドアの状態は既存エンジンに残す。
- モード中は `setPaused` で部屋のRAFを停止。非表示モードの一覧は保持し、地図・地球儀はアンマウントする。検索、フィルター、ページ、一覧スクロールを保持しつつGPUを解放する。
- `#/room/world`、`#/room/mountains`（JAPAN）、`#/room/pokemon` をブラウザ履歴に積む。旧 `#/world`、`#/japan`、`#/mountains`、`#/pokemon` と `#/index` は残す。

## データ・地図

TXT9ファイルとマスターは変更しない。`loadArchive` が1回読み込んだ `Archive` を部屋とモードに渡す。県訪問と登頂、通常色と色違いは互いに独立。写真・日付は既存DetailPanelで実在する記録だけ表示する。図鑑画像の新規取得は行わず、記号のプレースホルダーを表示する。

`Map` は既存のd3投影と県ポリゴン、百名山の座標を使用。山地図に `prefectures` を渡すと淡い県訪問色を表示する。選択した山は4倍表示で中央へ移動し、一覧とマーカーに選択状態が付く。拡大時に山名ラベルを表示。ホイール・2指の拡大縮小に対応する。世界地球儀は一覧選択時に国の地理的中心へ回転する。形状のない地域は一覧で閲覧できる。

## 更新時の注意

展示のIDは `destinations.ts` の既存IDを維持。JAPANは `japan` の展示から `mountains` モードへ入る。従来の `mountains` ID定義は互換のため残すが、入口・メニューは3つとする。Instagramなど外部入口は既存処理を使う。

スマートフォンのJAPAN一覧は最小・中間・最大ボタンとハンドルのスワイプで切り替える。地図・ハンドル・一覧のスクロール領域を分ける。造形・入力変更時は `collection-modes.spec.ts` と従来の部屋テストを両方確認する。
