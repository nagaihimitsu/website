# 3Dコレクションモード

## 構成

- `RoomHome` は入室中ずっと同じ `RoomEngine` を所有する。`CollectionModes` がモードの表示・履歴・詳細を担当し、`Collection` を旧独立URLと共用する。iframeやページ読み込みは使わない。
- `RoomEngine.open` は入力をクリアし、500msで展示へ接近する。`closeCollection` は遷移ロックを解除し、保存したカメラを復元する。歩行座標・視線・小物・ドアの状態は既存エンジンに残す。
- モード中は `setPaused` で部屋のRAFを停止。非表示モードの一覧は保持し、地図・地球儀はアンマウントする。検索、フィルター、ページ、一覧スクロールと地図・地球儀の表示位置を保持しつつGPUを解放する。
- `#/room/world`、`#/room/mountains`（JAPAN）、`#/room/pokemon` をブラウザ履歴に積む。旧 `#/world`、`#/japan`、`#/mountains`、`#/pokemon` と `#/index` は残す。

## データ・地図

TXT9ファイルとマスターは変更しない。`loadArchive` が1回読み込んだ `Archive` を部屋とモードに渡す。県訪問と登頂、通常色と色違いは互いに独立。「県のみ表示」では47県の一覧・検索・訪問フィルターに切り替え、山の検索条件は別に保持する。写真・日付は既存DetailPanelで実在する記録だけ表示する。図鑑画像の新規取得は行わず、記号のプレースホルダーを表示する。

`Map` は既存のd3投影と県ポリゴン、百名山の座標を使用。山地図に `prefectures` を渡すと淡い県訪問色を表示する。選択した山は4倍表示で中央へ移動し、一覧とマーカーに選択状態が付く。拡大時に山名ラベルを表示し、マーカーを画面上の大きさに合わせる。44pxの選択範囲内で最も近い山を選び、密集した不可視の選択領域が隣の山を遮らないようにする。ホイール・2指の拡大縮小に対応する。世界地球儀は一覧選択時に国の地理的中心へ回転する。形状のない地域は一覧で閲覧できる。

## 更新時の注意

展示のIDは `destinations.ts` の既存IDを維持。JAPANは `japan` の展示から `mountains` モードへ入る。従来の `mountains` ID定義は互換のため残すが、入口・メニューは3つとする。地球儀は背面中央より左へ寄せ、初期位置からの歩行経路と机・ベッドの配置を確保する。Instagramなど外部入口は既存処理を使う。

スマートフォンのJAPAN一覧は最小・中間・最大ボタンとハンドルのスワイプで切り替える。地図・ハンドル・一覧のスクロール領域を分ける。造形・入力変更時は `collection-modes.spec.ts` と従来の部屋テストを両方確認する。


## WORLDの固定表示と選択

`WorldMode` が国選択・検索・訪問フィルター・地域の開閉を所有する。WORLDから共通DetailPanelへは通知せず、選択した国は地球儀／2D地図上のラベルと固定情報欄、一覧のハイライトで示す。実在する写真・日付は一覧内の訪問記録として展開し、ページやモーダルを開かない。旧 `#/world` は記録の互換ページとして維持する。

`worldMode.css` は上下（広い画面は左右）のGridと `min-height: 0` で全体を `100dvh` 内に収める。検索・フィルターは一覧のスクロール領域の外に置く。`world-country-list` だけがスクロール可能。VisualViewportの高さ・オフセットにも追従し、アドレスバー／キーボードによる可視領域の変化を反映する。リスナーとCSS変数はモード終了時に解除する。逆選択のスクロールは一覧自身のscrollToで行い、祖先を動かすscrollIntoViewは使わない。逆選択の自動スクロールはその選択時に一度だけ行い、その後の手動スクロールや地域開閉、再入場時の位置復元を奪わない。選択情報は高さを固定し、国名によって地球儀の高さを変えない。

`Globe` のpaper表示は既存react-globe.glを使用。HTMLラベル層に日本語名を載せ、球面の座標・回転・ズーム・遮蔽に追従させる。カメラ補間は既存pointOfViewの500ms、経度180度以内の経路を使い、新しい選択で古い補間を中断する。カメラ情報はrefとDOM診断属性に保存し、毎フレームReact状態を更新しない。

代表点・地域は `world-view.json` の表示用アダプター。既存の固定Natural Earth 5.1.2と同じSHA-256のソースからSUBREGION／LABEL_X／LABEL_Yを抽出し、国が複数地理単位に分かれる場合は最大面積の単位を使う。東アジア・東南アジアなど23の小地域を使用し、外洋の島々のみ所在地域へ明示的に割り当てる。[分類方針・境界地域・例外](WORLD_REGIONS.md)を正本とする。形状のないBVT・GIB・UMIは概略代表点を明記し、UMIはミッドウェーを代表とする。実績を推測・追加する処理はない。

再生成は `node scripts/build-world-view.mjs /固定ソース/world.json`。参照元URLとSHAは `scripts/catalogs/sources.json` に固定。既存の国・地図マスターやTXTを再生成しない。表示リセットは向き・ズーム・選択・ラベルを初期化し、検索・フィルター・地域開閉は保持する。

`data-world-ready`、`data-view-lat/lng/altitude` は地球儀の検証用診断属性。選択IDはWORLDルートとラベル・行にも記録する。ブラウザ検証は `world-mode.spec.ts`、Safari系レイアウトは `playwright.world-webkit.config.ts` を使う。WebKit/LinuxのGPUの有無に依存させず、WebKit試験は2Dで可変高さ・縦横表示・タッチ選択を確認し、地球儀の実ピンチはChromiumのCDPタッチ入力で確認する。iPhone実機での検証とは区別する。

地域分類だけの変更は `npm run test:scope -- world-regions` で確認する。地球儀の描画・ジェスチャーや楽器は変更していなければ再試験しない。画面操作の変更には `world`、共有の入口・カメラの変更には対応する部屋テストを追加で選ぶ。通常pushはビルドのみで、必要な確認と記録は変更時に行う。
