# 部屋の女の子NPC

所有者が提供した正面・横・斜め・背面の参考画像をもとに制作。主人公・小鳥と同じ、自作のThree.js立体メッシュを使う。外部モデルや参考画像の板ポリゴンは使用せず、新しい依存パッケージも追加しない。

## 造形と動作

薄紫の丸いボブと分かれた前髪、紫色の大きい目、黄色のリボン、クリーム色の編み物のカーディガン、紺地に黄・白・緑の花柄ワンピース、茶色の斜め掛けバッグとサンダルを表現する。背面にも髪・カーディガン・肩ひも・花柄を持ち、360度見回せる。

部屋では元のモデルを縦・横・奥行きとも2倍に拡大し、全高約2.56m。[四方向の造形（元のモデル）](screenshots/visitor-comparison.png) ／ [部屋・PC](screenshots/visitor-room-desktop.png) ／ [部屋・390px幅](screenshots/visitor-room-mobile.png)。部屋では既存の照明とシャドウマップを共有する。

現在は床で待機するNPC。呼吸とまばたきを既存の部屋のアニメーションから更新する。歩行・会話・クリックによる機能は追加しない。メニュー中・タブ非表示中は部屋とともに停止し、「動きを減らす」で装飾的な動きを止める。

## 実装と更新

- `src/room/art/visitor.ts`：形状、素材、待機アニメーション。`createVisitor()` が `group`・`animate(time, reducedMotion)`・`dispose()` を返す。モデルの正面はローカル+Z。
- `src/room/roomScene.ts`：`room-visitor` の名前で室内の `(1.85, 0.012, -0.70)`、Y軸回転 `-0.20rad`、一様スケール `2` で配置。拡大に合わせて少し手前の右側へ寄せ、机の手前を歩いて回り込める隙間と主人公の初期位置からの通路を残している。
- 同じ場所で `Box3` により拡大後の髪・裾・バッグを含む可視形状の境界を取り、待機中の微動用に各方向3.6cmの余裕（元モデルの1.8cmも2倍）を加え、床からの衝突体を登録する。サイズや姿勢を変更した場合は、この余裕で動く範囲を包含できるか確認する。
- 衝突体は既存の保存位置検証と小鳥の生成より前に存在する。追加NPCと重なる古い保存位置は既存処理が安全な初期位置へ戻し、小鳥も同じ障害物一覧からNPCを避ける。保存形式・復元順序は変更しない。
- 壊せる小物の一覧には登録しない。パンチでも壊れず、「小物を元に戻す」でも位置・形状・衝突体は維持する。
- 形状・素材・生成テクスチャの解放は既存の `withDisposalScope` で所有し、部屋の破棄に合わせて一度だけ解放する。

造形を変更したら開発サーバーの `/scripts/visitor-study.html?view=front`、`side`、`back`、`quarter` で部屋と同じモデルを確認する。比較ページは開発専用で本番ビルドには含めない。部屋ではPCと狭い縦画面でも確認し、配置変更では家具との隙間と主人公・小鳥の通行を再確認する。

## 検証方法

`npm run test:scope -- npc` は小鳥・NPC造形・移動の単体テストと、両NPC・部屋描画のブラウザテストを選ぶ。女の子の専用テストは `tests/room-visitor.test.ts` と `tests/e2e/visitor.spec.ts`。本番ビルドは `npm run build`。

今回実施した結果と未確認事項は [検証記録](VALIDATION.md) に記載する。過去のキャラクター検証を今回の結果には含めない。
