# 部屋のコレクション展示

## 図鑑端末と写真立て

机上の図鑑は、写真立てと同程度か少し小さく見えるよう、本体と台座の親 `pokedex-stand` を0.58倍にする。写真立て自体は変更しない。親の位置は机のローカル座標で `[-0.45, deskSurface, 0.2]`、本体はその中の `[0, 0.82, 0]`。旧来の本体寸法・赤い素材・画面テクスチャ・開いた蓋を使い、卓上へ沈まず、写真より少し低く収まる。

本体、台座、見えないクリック範囲を同じ親で縮小する。入口の `pokemon` ID、通常色・色違いの集計と画面生成は維持する。ラベル位置と注視点は本体のローカル座標からfurniturePointで求め、親の縮小や傾きを反映する。

## ベッド上の日本ポスター

日本地図＋百名山の入口は、棚上の模型からベッドの頭側の壁へ移す。中心は `[bedLayout.position[0], 2.7, -3.92]`。額の幅1.24・高さ1.78・厚さ0.06、地図面は1.12×1.6で、元の700×1000の地図テクスチャの縦横比を維持する。壁の室内側面と額の背面に隙間を取り、下端をヘッドボードより上に置く。

木の額、生成りのマット、既存の訪問県色付き地図を使用し、額の下辺に小さな山の意匠を置く。新しい画像・データ・ライブラリは導入しない。表示オブジェクト名は `japan-wall-poster`、入口IDは既存の `japan` のまま、開く先も `#/room/mountains` のJAPANモードを維持する。

入口のラベル位置と注視点はポスター自身のローカル座標から算出する。接近カメラは注視点の `[0, 0.15, 2.2]` 手前へ移し、壁面を正面寄りに見る。棚と本は装飾・足場として残し、保存互換性のため歩行障害物 `mountain-console` のID・形状は変更しない。

## 変更と確認

造形・配置・クリック範囲は `roomScene.ts`、JAPANへの接近方向は `roomEngine.ts`、ベッド・机の基準位置は `furnitureLayout.ts`。写真立て・地球儀・通常のホームカメラは変更しない。新しい保存キーや表示モードを追加しない。

今回のような配置変更では、実物のクリックと配置画像を確認する。必要なケースだけを次のように選ぶ。

```bash
npx playwright test tests/e2e/room.spec.ts tests/e2e/collection-modes.spec.ts --grep '図鑑端末本体|日本ポスター' --reporter=list
```

日本ポスターのケースは起動、地図・一覧の連動、ホームカメラの復元と同じcanvasの保持、再入場を確認する。図鑑のケースは縮小後の本体をクリックして既存モードが開くことを確認する。楽器・他のUIの全テストを毎回実行しない。検証画像は今回の変更と区別できる/tmpへ保存し、過去の追跡画像を無関係に上書きしない。変更理由・検証・公開結果はVALIDATIONにも記録する。
