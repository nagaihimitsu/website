## 操作・データ

- ↕：上下どちらも同じスラップ。24px以上・250ms以内・平均0.09px/ms以上・縦/横比1.35以上。開始音高を固定し、同じ発音を再トリガーしない。
- slide：同一弦の1〜5F。横12px以上・横/縦比1.35以上で横移動へ固定。行の外へ出た経路や大きな逆行は失敗。別のセルのタップは作らない。
- 初期設定は `bassGesture.ts` のBASS_GESTURE_CONFIG、演出はBASS_EFFECT_CONFIG、予告はBASS_VISUAL_CONFIG。スライド時間は譜面のendTime-timeで指定する。
- slideノーツは既存のid/time/midi/string/fretに加え、endTime/endMidi/endString/endFretを持つ。同一弦・異なるフレット・正しいMIDI・終了が開始より後であることを共通の`validateBassSlide`で検査する。
- slideは同じ音高でも始点の弦/フレットを正確に照合する。通常・ホールド・スラップの同音別位置は従来どおり正解。
- 終点の0.28F以内への最初の到達時刻と開始時刻の悪い方を採用。早く到達して待ってもExcellentにはならない。採点・コンボは最後に1回だけ。中途解除・キャンセル・別弦・タイムアウトはMiss。
- ポーズ時は音声と接触を解放し、進行中のslideをMissで終了する。従来のホールドの拾い直しは維持する。
- 指板の水平経路はSVGの`userSpaceOnUse`で始点・終点を明示し、高さ0のobjectBoundingBoxで色が消える問題を回避する。左右両方向の座標をE2Eで検査する。
- 始点は通常チャージ、終点は細いカウントダウン枠。経路は音名の下に描画し、音名が最前面。タイムラインのX座標は時刻に比例し、帯の長さを偽らない。

## 遊べる検証譜面

曲選択の **「奏法練習 · Garden-Party」** は、既存の伴奏を使う手書きの練習・検証譜面。既存譜面への自動スライド挿入ではない。1秒のタップ、2→3秒の3弦2F→5F、4→5秒の逆方向、6/7秒のスラップ、8→9秒のホールド、10秒から125ms間隔8連打などを含む。通常の採点方式を共用する。

MIDI譜面へ後から手動設定する場合の保存例（原本は不変）：

```bash
npm run chart:final-hit -- --note nNNNN --kind slide --technique slide --string 3 --fret 2 --end-string 3 --end-fret 5 --end-time 12.5
```

開始MIDIに一致する1〜5Fの実位置が必要。`--end-time`は元音声内の絶対秒で、共通audioOffsetが開始と終了へ同量適用される。これは指定例であり、nNNNNは実在のIDに置き換える。未確認フラグを勝手にtrueへ変更しない。

## 主人公演出

成功確定イベントの連番を消費し、再描画やpointerupによる二重発生を防ぐ。通常は弦付近の短い光と星、Excellentは星と光の強化、スラップは環状衝撃波、スライドは実ネック上を方向に沿って走る光。保持中は持続光を表示する。スライド中の既存の押弦手も連続フレット座標へ追従する。0〜19 / 20〜49 / 50以上で花びら・音符と花の揺れの段階を変える。キメの自動推定は追加しない。

新しい3D演出は12スロットの固定プール。Miss/Badは成功専用演出を発生させない。共通曲時計で寿命を算出し、動き抑制時は星・衝撃波・移動軌跡を抑える。既存の花びら24個・音符8個の上限も維持する。
